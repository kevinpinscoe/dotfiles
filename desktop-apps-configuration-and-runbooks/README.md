# Desktop Application Configuration and Runbooks

Operational notes, installation procedures, and personal usage notes for GUI and desktop applications across all three platforms:

- **macOS Tahoe** (Apple Silicon)
- **Fedora Linux 42 KDE Plasma 6** (x86_64)
- **Raspberry Pi 5 — Debian Trixie LXDE** (aarch64)

## Structure

Each application gets its own directory containing a `RUNBOOK.md` and any supporting files. Platform-specific content lives in named sections within the single RUNBOOK, not in separate files.

```
<AppName>/
├── RUNBOOK.md          ← procedures, personal notes, and troubleshooting
└── <supporting files>
```
